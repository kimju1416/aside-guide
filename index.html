Aside가 뭔가요?

대화만 하는 챗봇이 아니라, 브라우저 안에서 직접 클릭하고 입력하는 AI예요.

Aside는 크롬과 같은 Chromium 엔진으로 만든 브라우저에 AI 에이전트를 얹은 제품이에요. 탭을 열고 검색하는 건 평소 쓰던 브라우저와 똑같아요. 다른 점은 입력창에 할 일을 적으면 AI가 이미 로그인해 둔 사이트에 들어가 메뉴를 누르고, 내용을 읽고, 파일을 받아 오는 일까지 이어서 한다는 거예요.

일반 채팅형 AI는 사람이 자료를 복사해 붙여 넣어야 답을 해 줘요. Aside는 메일함·대시보드·업무 도구 화면을 직접 보면서 일해요. 따로 연동(API)을 만들지 않아도, 사람이 볼 수 있는 화면이면 다룰 수 있다는 게 핵심이에요.

2

설치와 첫 설정

핵심은 쓰던 브라우저의 기록과 로그인 상태를 옮겨 오는 거예요.

준비물

  • 컴퓨터 — 윈도우 PC 또는 macOS 15.0 이상 맥. Aside가 곧 브라우저라서 따로 맞춰야 할 브라우저 버전은 없어요.
  • Aside 계정 — 설치 중에 만들 수 있어요. Aside가 기본 제공하는 AI 모델을 쓰려면 로그인이 필요해요.
  • (선택) 쓰던 브라우저 — 방문 기록·쿠키·북마크를 옮겨 오면 바로 일을 맡기기 편해요.

따라 하기

설치 파일 받아 실행

aside.com/download에서 내 운영체제용 설치 파일을 받아 실행해요.

로그인 또는 계정 만들기

첫 화면에서 로그인하거나 새 계정을 만들어요. 이메일 인증도 같은 화면 안에서 끝나요.

브라우저 데이터 가져오기

가져올 브라우저를 고르고, 프로필이 여러 개면 원하는 프로필을 골라요. 시스템 접근을 허용하고 가져오기가 끝날 때까지 기다려요. 사파리는 사파리에서 파일 › 내보내기로 만든 ZIP 파일을 올려요.

비밀번호 보관함(Aside Vault) 설정

보관함을 켜고, 크롬·엣지·1Password 같은 곳에서 비밀번호를 가져와요. 건너뛰었다가 나중에 설정해도 돼요. 자세한 내용은 10장.

AI 구독 연결(선택) 후 첫 작업

이미 쓰는 ChatGPT·Claude 구독이 있으면 연결하고(9장), 원하는 결과와 사이트를 적어 첫 작업을 보내요.

💡
쿠키를 가져오는 이유

쿠키에는 사이트 로그인 상태가 들어 있어요. 기존 브라우저에서 로그인해 둔 사이트를 Aside에서도 이어 쓸 수 있어서, AI에게 일을 맡길 때 로그인부터 다시 할 일이 줄어요.

⚠️
가져오기가 실패하면

원래 브라우저 프로필이 아직 있는지 확인하고, 원래 브라우저를 완전히 닫은 뒤 다시 시도해요. 같은 브라우저 프로필은 한 Aside 프로필에 두 번 가져올 수 없어요. 화면에 뜨는 오류는 Browser import failed., 사파리는 Please upload a ZIP file 또는 Failed to read the ZIP file 등이에요.

프로필을 여러 개 쓸 때

  • 새 프로필은 로컬 프로필로 만들어져요. 온보딩 없이 바로 열리고, 로그인은 나중에 새 탭 페이지에서 해도 돼요. 그 프로필에서 Aside 제공 AI를 쓰려면 로그인이 필요해요.
  • 프로필 이름을 바꿀 수 있어요. Aside 계정 이름 대신 내가 정한 프로필 이름이 보여요.
  • 작업과 루틴은 만든 프로필에 묶여요. 브라우저를 다시 켜거나 창·프로필을 바꿔도 원래 프로필에서 돌아요.
3

화면 구성 둘러보기

세로 탭 사이드바, 에이전트 전용 탭 묶음, 새 탭 페이지, 오른쪽 사이드 패널이 기본 뼈대예요.

📑

세로 탭 사이드바

맨 위에 Chats(대화) 섹션, 그 아래 고정 탭과 일반 탭이 있어요. Ctrl+S로 접고 펴고, 접었을 때는 창 왼쪽 끝에 마우스를 대면 떠 있는 사이드바가 나와요.

🤖

Agent Tabs

AI가 일하면서 연 탭과 팝업이 한 묶음으로 모여요. 기본으로 음소거되고, CLI·MCP로 연결한 외부 에이전트가 쓰는 탭도 여기로 모여요.

🏠

새 탭 페이지

주소창에 Search·Ask AI 두 모드가 있어요. Chats·Routines 탭의 안 읽은 배지, 루틴 카드, 작업 미리보기가 보이고 승인 요청도 여기서 처리해요.

💬

사이드 패널 (Ask Aside)

오른쪽에 열리는 AI 창이에요. 보고 있는 페이지를 붙인 채 일을 맡기고, 폭은 끌어서 넓힐 수 있어요.

탭 다루기

  • 고정 탭(Pinned Tabs) — 탭을 오른쪽 클릭해 고정하거나, 세로 탭에서 맨 위로 끌어 올려요. 클라우드로 동기화돼요.
  • 탭 스위처 — 탭이 두 개 이상일 때 Ctrl+Tab. 최근 사용 순서로 볼지 사이드바 순서로 볼지 설정에서 고를 수 있어요.
  • 분할 보기(Split View) — Ctrl+Shift+\로 두 페이지를 나란히 띄워요. 원본 문서를 보면서 폼을 채우거나, AI가 일하는 화면을 옆에서 지켜볼 때 좋아요.
  • 북마크 섹션 — Settings › Appearance › Customize sidebar에서 사이드바에 북마크 칸을 켤 수 있어요.
  • 가로 탭 모드 — 크롬처럼 위쪽 가로 탭으로도 쓸 수 있고, 탭 폭을 창에 맞춰 줄이는 옵션은 Settings › General에 있어요.
  • 자동 PiP — 영상을 보다가 다른 탭으로 가면 작은 창으로 띄워 줘요. 기본은 꺼져 있고 Settings › General에서 켜요.
  • 메모리 세이버 — 안 쓰는 탭의 메모리를 줄이는 기능이 기본으로 켜져 있어요(9월 10일 판부터).
ℹ️
AI가 쓰던 탭을 내가 쓰고 싶을 때

Agent Tabs 안의 탭을 누르면 따로 넘겨받기(Take over) 버튼을 누르지 않아도 일반 페이지처럼 쓸 수 있어요. 다른 탭으로 옮기면 그 탭은 다시 Agent Tabs 묶음으로 돌아가요(9월 14일 판).

일을 맡기는 입구

여러 사이트·파일을 오가는 일은 작업 페이지, 지금 보는 페이지가 기준이면 사이드 패널이에요.

기준이 될 페이지 열기

일의 출발점이 되는 페이지(급여 포털, 계약서, 대시보드 등)를 열어요.

Ctrl+E를 누르면 오른쪽에 Ask Aside가 열려요.

페이지 첨부 확인

입력창 위에 페이지 제목과 주소가 붙어 있어요. 이 페이지 없이 시작하려면 첨부를 지워요.

할 일 적고 보내기

결과·저장 위치·멈출 지점을 적어 보내요(6장).

알아 두면 편한 동작

  • 초안은 페이지별로 남아요. 쓰다 말고 다른 페이지로 갔다 와도, 시작한 탭에 초안이 붙어 있어요.
  • 탭을 바꿔도 대화 유지 — 탭을 옮겨도 사이드 패널의 현재 대화를 그대로 두는 설정이 있어요. 페이지 첨부 칩은 지금 보는 탭을 따라가요.
  • @로 맥락 붙이기 — 입력창에서 @를 치면 열린 탭·파일 등을 골라 붙여요. 입력창 안내 문구는 Ask AI a task, @ for context예요.
  • 붙일 수 있는 파일 — PDF, DOC·DOCX, PPT·PPTX, XLS·XLSX, 이미지(아이폰 HEIC는 자동으로 PNG로 바꿔 읽어요), 로컬 폴더.

미니 팝업

어느 프로그램 위에서든 단축키로 작은 채팅창을 불러와요. 창 안에서 새 대화 시작, 대화 전환, 파일 첨부, @ 첨부, 모델·프로필·프로젝트 선택까지 할 수 있어요. 끌어서 옮기거나 크기를 바꾸고, Esc로 닫아요. 다시 열면 마지막 위치와 크기를 기억해요. 단축키는 Settings › Keyboard shortcuts 또는 Settings › Mini popup에서 정해요.

입구 고르는 한 줄 기준

Full access는 파일 접근 범위만 넓혀요. 저장된 비밀번호 값은 어떤 권한에서도 AI에게 드러나지 않아요. 그래도 컴퓨터 전체를 읽고 쓰는 권한이니, 꼭 필요한 작업에서만 켜세요.

에이전트 기본 권한 · Settings › Agents

작업마다 정하는 것과 별개로, 모든 작업에 적용되는 기본 규칙이 있어요. Settings › Agents에서 아래로 내리면 권한 구역이 나와요.

  • Sandbox — AI가 명령을 실행할 때 운영체제 수준으로 격리할지 정해요.
  • File permissions — AI가 볼 수 있는 폴더, 고칠 수 있는 폴더 목록이에요.
  • Tool permissions — 도구마다 아래 세 값 중 하나를 붙여요.
값동작
Allow묻지 않고 바로 써요
Ask쓰기 전에 사용자에게 물어봐요
Deny막아요. Deny는 Ask·Allow보다 항상 우선해요

작업에 따로 정한 권한이 있으면, 그 설정이 에이전트 기본값 위에 덧씌워져 적용돼요. 실행 중인 작업에서도 모델과 권한을 바꿀 수 있어요.

공식 문서가 꼽은 나쁜 예는 Handle my billing.(청구 건 처리해 줘) 한 줄이에요. AI는 어느 계정인지, 무엇을 만들어야 하는지, 어디까지 해도 되는지 모르니 엉뚱한 곳을 헤매거나 중간에 멈춰요.

  1. 원하는 결과 — “정리해 줘”보다 “날짜·가게·금액·결제수단 열로 된 표”처럼 구체적으로.
  2. 사이트·계정·파일 — 어디서 일할지 이름을 적어요.
  3. 저장 위치와 형식 — 다운로드 폴더, 파일 이름 규칙, 표 열 이름.
  4. 멈출 지점과 하지 말 일 — 보내기·게시·결제·설정 변경 전에 멈추라고 적어요.
  5. 물어볼 조건 — 인증번호, 애매한 선택이 나오면 물어보라고 적어요.

MCP 서버: 외부 도구 붙이기

  • 무엇 — MCP(Model Context Protocol)는 AI에 외부 도구를 연결하는 표준 방식이에요. 연결하면 Aside 에이전트가 그 도구의 기능을 쓸 수 있어요.
  • 연결 — MCP 설정 화면의 서버 추가 대화상자에서 로컬 서버나 인증이 필요한 HTTP 커넥터를 추가해요. 인증이 필요한 서버는 도구를 쓰기 전에 OAuth 로그인을 먼저 띄워 줘요.
  • 실패하면 — 연결 실패 알림과 실제 오류 문구, 로컬 서버의 오류 출력을 보여 줘요.
ℹ️

직무별 활용 사례

공식 블로그의 직무별 사례를 요지만 우리말로 정리하고, 바로 쓸 지시문을 붙였어요.

공통 원칙

  1. 근거를 남기게 해요 — 모든 결과에 출처 링크와 스크린샷을 붙이라고 적어요.
  2. 마지막 버튼은 사람이 — 승인·보내기·결제·약관 동의·저장은 사람이 확인한 뒤에 해요.
  3. 애매하면 표시하게 해요 — “확인 필요”, “변경”, “없음”처럼 상태를 나눠 적게 해요.
  4. 세 번 반복되면 루틴으로 — 파일 이름 규칙, 담당자, 사이트 특이사항을 루틴에 담아 다음 실행과 비교해요.

운영·행정

  • 월요일 보고 묶음 — 대시보드 여러 개를 열어 지난주와 비교하고 예외만 뽑아요.
  • 갱신 계약 확인 — 업체 관리 페이지에서 사용 인원과 갱신일을 적고 30일 안에 오는 건을 표시해요.
  • 월말 청구서 수집 — 포털마다 PDF를 받아 이름 규칙대로 저장하고, 못 받은 곳을 적어요.
  • 중복 도구 찾기 — 도구 목록과 관리 콘솔을 대조해 겹치는 구독을 증거와 함께 모아요.
운영 · 갱신 확인
우리가 쓰는 주요 구독 서비스 다섯 곳의 관리자 페이지에 들어가서 현재 사용 인원과 다음 갱신일을 스프레드시트에 적어 줘. 30일 안에 갱신되는 곳은 표시하고, 각 값에 확인한 페이지 링크를 붙여. 결제나 요금제 변경은 하지 마.

연구·조사

  • 변화 추적 — 지난달 보고서의 주장과 지금 웹페이지를 비교해 “변경·없음·검토 필요”로 나눠요.
  • PDF 자료 추출 — 데이터베이스에서 논문을 받아 파일 이름을 정리하고 필요한 항목을 뽑아요. 애매한 값은 표시해요.
  • 가격 페이지 스냅숏 — 여러 업체의 요금제 이름·한도·주소를 스크린샷과 함께 남겨요.
  • 방문 기록 되찾기 — 지난달 열었던 자료를 방문 기록에서 찾아 다시 열고 관련성을 설명하게 해요.
연구 · 기존 보고서 검증
첨부한 보고서에 나오는 출처 링크를 하나씩 열어 지금 화면을 스크린샷으로 남기고, 보고서 속 주장과 비교해 줘. 결과는 링크 · 보고서 주장 · 현재 내용 · 상태(유지/변경/없음) 열의 표로 만들고, 변경·없음에는 근거를 붙여.

영업·대외 협력

  • 미팅 전 준비 — 상대 회사의 채용·보안·최근 변경 페이지와 비슷한 사례를 모아 질문 목록과 위험 요소를 만들어요.
  • 연락처 정리 — 웹사이트를 확인해 회사 규모·업종 수정안을 “바꾸기 전/후 + 출처”로 제안하되 저장은 하지 않아요.

  • 명단 만들기 — 협회 디렉터리를 돌며 필요한 항목을 뽑아 CSV로 내보내고 빠진 칸을 표시해요.

  • 에이전트 — 목표를 받으면 여러 단계를 스스로 이어서 실행하는 AI.
  • 작업(Task) — AI에게 맡긴 일 한 건. 대화 기록·만든 파일·권한 설정이 함께 묶여요.
  • Agent Tabs — AI가 일하며 연 탭을 모아 두는 묶음.
  • Steer / Queue — 진행 중에 보낸 메시지를 바로 반영할지(Steer), 끝나고 반영할지(Queue).
  • 루틴(Routine) — 일정이나 이벤트에 맞춰 자동으로 도는 작업.
  • Ultrabrowse — 출처가 많이 필요한 조사용 고급 모드(Pro 이상).
  • 크레딧 — Aside 제공 모델을 쓸 때 차감되는 사용량 단위.
  • Vault — Aside의 비밀번호 보관함. AI에게 비밀번호를 보여 주지 않고 자동 입력만 해요.
  • 샌드박스 — 명령이 컴퓨터의 다른 부분을 건드리지 못하게 가두는 격리 공간.
  • MCP — AI에 외부 도구를 연결하는 표준 방식(Model Context Protocol).
  • OAuth — 비밀번호를 넘기지 않고 팝업 로그인으로 다른 서비스 연결을 허락하는 방식.
